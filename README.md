# 📊 Dashboard de Indicadores

Painel web interativo de indicadores de desempenho, com KPIs e gráficos
consumindo dados estruturados de banco SQL, aplicando princípios de
DataViz e Data Storytelling.

## 🛠️ Tecnologias
HTML5 • CSS3 • JavaScript • Chart.js • SQL • Git

## ✨ Funcionalidades
- 4 KPIs calculados dinamicamente (vendas totais, média mensal, variação, canal líder)
- Gráfico de linha: evolução de vendas mensais
- Gráfico de rosca: participação por canal de venda
- Design responsivo com tema escuro
- Modelagem SQL completa com consultas de agregação (GROUP BY, SUM, AVG)

## ⚙️ Como rodar
1. Clone o repositório
2. Abra o `index.html` no navegador — sem dependências para instalar
3. (Opcional) Execute `database/script.sql` no SQL Server para ver a modelagem do banco
